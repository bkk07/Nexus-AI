# Enterprise Security Policy 2026

## Access Control
All employees must use multi-factor authentication (MFA) with FIDO2 hardware keys to access internal infrastructure. Password resets must be triggered through the self-service IT portal.

## Incident Response
In the event of a suspected breach, the Security Operations Center (SOC) must be notified immediately via the emergency Slack channel `#soc-incident`. The target mitigation time for Severity 1 incidents is 15 minutes.
